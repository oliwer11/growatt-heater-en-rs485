## Notes

- The RS485 pinout used by this project is on page 16 of the printed SPH
  installation manual (PDF page 20), section 5.2. It is the same for the
  `485-1`, `485-2`, `485-3` and `METER` sockets — what differs is which of them
  has the inverter acting as a Modbus slave. See the main
  [README](../README.md#finding-the-right-port--read-this-before-wiring).
